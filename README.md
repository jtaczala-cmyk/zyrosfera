# Aetheris (dawniej ŻyroSfera)

Prototyp gry mobilnej z sterowaniem dotykowym / żyroskopem.

## Jak uruchomić grę (zalecane)

1. Wejdź w **Settings** → **Pages** w tym repozytorium.
2. Source: **Deploy from a branch**
3. Branch: **main** / folder: **/ (root)**
4. Kliknij **Save**.

Po 1-2 minutach gra będzie dostępna pod adresem:

**https://jtaczala-cmyk.github.io/zyrosfera/**

Otwórz ten link na telefonie i dotknij Start. Przeciągaj palcem, żeby sterować sferą.

## Pliki

- `index.html` — główny prototyp (Three.js)
- `GDD.md` — dokument projektowy
